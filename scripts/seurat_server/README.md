# Historical Seurat Ubuntu execution scripts

These scripts were extracted from `Dataset_{0,3,4,5}_Source_Code.zip`. Only the latest Python runner and one copy of generated R per dataset are kept; per-seed logs, failed run logs and backups were excluded. These scripts preserve historical execution code and host-specific environment/path assumptions. They do not form a supported Colab runtime.

Data and pretrained model files are not vendored. The notebooks in `notebooks/high_level` are the recommended high-level entrypoints; use these server scripts only for provenance or carefully adapted reruns.
