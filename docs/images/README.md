# Documentation screenshots

This directory contains the WebP previews used by the repository documentation:

- `report_overview.webp` — interactive report **Overview**.
- `report_rare_explorer.webp` — **Rare-cell Explorer** diagnostics.
- `report_seed_stability.webp` — native **Seed Stability** / multi-seed workspace.
- `comparator_methods_v10.webp` — **Multi-Report Comparator v10** methods-on-dataset view.

The root `README.md` and `INTERACTIVE_REPORTS.md` reference these files directly. They are documentation-only assets and are not required by scRareBench at runtime.

When replacing a screenshot, keep the same filename unless every Markdown reference is updated as well. Avoid private paths, credentials, tokens, or unrelated browser chrome in captures.
